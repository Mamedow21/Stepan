# План и протокол тестирования

## 1. Объект и цель

Объект тестирования — консольная «Система учёта студентов» (Вариант 5,
Способ 1). Цель — подтвердить соответствие поведения системы
спецификации, найти дефекты и обеспечить покрытие ветвей не ниже 75 %.

Я выбрал фреймворк `unittest` из стандартной библиотеки Python, для
статического анализа — `flake8`, для измерения покрытия — `coverage`
(режим `--branch`).

## 2. План тестирования

| Этап | Что делаю | Инструмент | Критерий завершения |
| --- | --- | --- | --- |
| 1 | Анализ спецификации, выделение причин и следствий | таблица решений | все следствия E1..E8 покрыты |
| 2 | Модульные тесты `Student`, `StudentRegistry`, `ReportBuilder` | `unittest`, `subTest` | все тесты проходят |
| 3 | Тесты хранилища с изоляцией файлов | `tempfile.TemporaryDirectory`, `unittest.mock` | нет временных файлов после тестов |
| 4 | Интеграционные тесты конвейера `src.main` | `unittest`, `contextlib.redirect_*` | коды возврата 0/1, файлы созданы |
| 5 | Инспекция кода | `flake8` | 0 замечаний |
| 6 | Измерение покрытия | `coverage --branch` | ≥ 75 % (цель — 95–100 %) |
| 7 | Регрессия в CI | GitHub Actions, Python 3.11–3.13 | 3 успешных задания |

Критерии входа: код собран, `python -m src.main --demo` выполняется.
Критерии выхода: 0 открытых дефектов, все тесты зелёные, порог покрытия выполнен.

## 3. Анализ причинно-следственных связей

### Причины

| Код | Причина (входное условие) |
| --- | --- |
| C1 | Реквизиты студента корректны (зачётка из цифр и дефиса, ФИО ≥ 2 слов, группа непуста, курс 1..6) |
| C2 | Все оценки — целые числа в диапазоне 2..5 |
| C3 | Список оценок непуст |
| C4 | Среди оценок есть неудовлетворительная (2) |
| C5 | Минимальная оценка не ниже 4 |
| C6 | Все оценки равны 5 |
| C7 | Номер зачётки уже есть в реестре |
| C8 | Студент учится на последнем (6-м) курсе |

Ограничения: `C6 → C5 → ¬C4`; `¬C3 → ¬C4 ∧ ¬C5 ∧ ¬C6`.

### Следствия

| Код | Следствие | Логика |
| --- | --- | --- |
| E1 | Студент зарегистрирован в реестре | `C1 ∧ C2 ∧ ¬C7` |
| E2 | `ValidationError`, реестр не изменён | `¬C1 ∨ ¬C2` |
| E3 | `DuplicateStudentError`, реестр не изменён | `C1 ∧ C2 ∧ C7` |
| E4 | Студент — отличник | `E1 ∧ C3 ∧ C6` |
| E5 | Студент — должник | `E1 ∧ C4` |
| E6 | Назначена стипендия | `E1 ∧ C3 ∧ C5` |
| E7 | Переведён на следующий курс | `E1 ∧ ¬C4 ∧ ¬C8` |
| E8 | В переводе отказано | `E1 ∧ (C4 ∨ C8)` |
