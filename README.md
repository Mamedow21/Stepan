# Stepan — Система учёта студентов

Учебный проект по дисциплине «Инструментальные средства разработки
программного обеспечения», лабораторная работа №4 (Вариант 5, Способ 1).

## Назначение

Я реализовал консольную систему учёта студентов: хранение контингента,
расчёт среднего балла, определение отличников, должников и получателей
стипендии, перевод на следующий курс, поиск по группе и фамилии,
формирование аналитических отчётов и сохранение ведомости в JSON.

## Структура

| Файл | Назначение |
| --- | --- |
| `src/errors.py` | иерархия исключений |
| `src/student.py` | модель студента и валидация |
| `src/registry.py` | реестр контингента |
| `src/storage.py` | JSON-хранилище (атомарная запись) |
| `src/report.py` | аналитические отчёты |
| `src/main.py` | консольный конвейер |
| `tests/` | модульные и интеграционные тесты |

## Запуск

```powershell
python -m src.main --demo --data students.json --report report.txt
```

## Тестирование

```powershell
python -m unittest discover -s tests -v
python -m coverage run --branch --source=src -m unittest discover -s tests
python -m coverage report --show-missing
```
